# Roadmap

## Milestone 1 — Assistant shell

Current MVP scope:

- Phone-first home and call interface
- Realtime conversational voice
- Camera and microphone lifecycle
- Structured weight capture
- Local history
- Offline/manual fallback

Completion requires live API and iPhone Safari validation.

## Milestone 2 — Guided capture

- Deterministic capture-state machine
- Functional face/body alignment overlay
- Head and body pose checks
- Lighting, sharpness, and motion checks
- Stable-frame selection

## Milestone 3 — Observer

- Face and body landmarks
- Segmentation
- Robust temporal aggregation
- Capture-quality metadata
- Versioned landmark storage

## Milestone 4 — Longitudinal engine

- Personal baseline
- Measurement variance and reliability
- Rolling statistics
- Confidence of real change
- Novelty thresholds

Later domains—facial geometry, physique, skin/hair, training, nutrition, and N=1 experiments—build on these measurement foundations rather than bypassing them.
